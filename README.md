# CodeAlpha_basic_chatbot
A rule-based chatbot built with core Python fundamentals — if-elif logic, functions, loops, and I/O.
# 🤖 RuleBot — Rule-Based Chatbot in Python

> Task 4 of my Python Learning Journey

A simple yet well-structured rule-based chatbot built using core Python
fundamentals. No external libraries, no machine learning — just clean,
readable Python logic.

---

## 📌 About the Project

This chatbot accepts natural language input from the user and responds
with predefined replies based on keyword matching using if-elif-else
conditions. It demonstrates how much you can build with just the basics.

---

## 🧠 Key Concepts Used

| Concept | Usage |
|---|---|
| `if-elif-else` | Pattern matching user input to generate replies |
| Functions | `get_bot_reply()` for logic, `run_chatbot()` for the loop |
| `while` loop | Keeps the chatbot running until the user exits |
| `input()` / `print()` | Reads user messages and displays responses |
| String methods | `.lower()` and `.strip()` to normalize user input |

---

## 💬 Supported Inputs

| User Says | Bot Replies |
|---|---|
| hello / hi / hey | Hi there! Great to meet you! |
| how are you | I'm doing great, thanks for asking! |
| what's your name | I'm RuleBot! |
| tell me a joke | Why do programmers prefer dark mode?... |
| thank you / thanks | You're welcome! Happy to help! |
| what can you do | Lists all supported commands |
| bye / goodbye | Goodbye! See you next time! |
| anything else | Fallback message with suggestions |
